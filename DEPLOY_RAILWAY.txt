================================================================
  GREENPLAST — Despliegue en Railway (link permanente)
================================================================

Railway es gratuito para este nivel de uso y entrega un link
permanente tipo: https://greenplast-mantenciones.up.railway.app

================================================================
PASO 1 — Crear cuenta en GitHub (si no tienes)
================================================================
  1. Ve a https://github.com
  2. Crea una cuenta gratuita con tu correo corporativo

================================================================
PASO 2 — Subir el código a GitHub
================================================================
  1. En GitHub, crea un repositorio nuevo:
     - Nombre: greenplast-mantenciones
     - Privado (recomendado)
     - Sin README (ya tienes los archivos)

  2. Instala Git: https://git-scm.com/download/win

  3. Abre una terminal (cmd o PowerShell) en la carpeta
     App_Mantenciones y ejecuta:

     git init
     git add .
     git commit -m "Primera versión"
     git remote add origin https://github.com/TU_USUARIO/greenplast-mantenciones.git
     git push -u origin main

================================================================
PASO 3 — Crear proyecto en Railway
================================================================
  1. Ve a https://railway.app y crea cuenta con GitHub
  2. Clic en "New Project" → "Deploy from GitHub repo"
  3. Selecciona el repositorio greenplast-mantenciones
  4. Railway detecta automáticamente que es Python/Flask

================================================================
PASO 4 — Configurar variables de entorno en Railway
================================================================
  En el panel de Railway → tu proyecto → Variables:
  Agrega estas variables:

  APP_PASSWORD    = [la contraseña que usará el equipo]
  SECRET_KEY      = [cualquier texto largo y aleatorio]
  API_SECRET      = [clave para el scheduled task, ej: gp-cal-2024]

================================================================
PASO 5 — Agregar volumen para la base de datos
================================================================
  Railway necesita un volumen persistente para que la BD
  no se borre al actualizar la app:

  1. En Railway → tu proyecto → "+ New" → "Volume"
  2. Mount path: /app/data
  3. Agrega esta variable de entorno adicional:
     DATABASE_PATH = /app/data/mantenciones.db

================================================================
PASO 6 — Obtener el link
================================================================
  1. En Railway → Settings → Networking → Generate Domain
  2. Copia el link (ej: https://greenplast-mantenciones.up.railway.app)
  3. Comparte ese link con todo el equipo

================================================================
PASO 7 — Actualizar la tarea de Cowork (calendario automático)
================================================================
  Una vez tengas el link de Railway, díselo a Claude en Cowork
  para que actualice la tarea programada greenplast-calendar-sync
  con la URL real del servidor.

================================================================
ACTUALIZACIONES FUTURAS
================================================================
  Cada vez que edites un archivo y hagas:
    git add . && git commit -m "cambio" && git push
  Railway redespliega automáticamente en segundos.
